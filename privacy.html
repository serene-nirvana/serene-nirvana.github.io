Privacy policy

Last updated October 03, 2026

This website

This site has no accounts, cookies, analytics or advertising, and we collect no personal information through it. It is hosted on GitHub Pages; GitHub may log visitors’ IP addresses for security purposes under its own privacy statement. Links to YouTube and payment platforms take you to those services, which have their own privacy policies.

The Serene Nirvana Bot application

Serene Nirvana Bot is a private tool used only by Serene Nirvana to manage its own YouTube channel. It uses Google’s OAuth sign-in and the YouTube Data API and YouTube Analytics API to:

  • upload videos and thumbnails to our own channel and schedule when they go public;
  • create and organise playlists on our own channel;
  • read our own channel’s viewing statistics to decide which kinds of videos to make next.

It requests only the permissions needed for these tasks, accesses only the channel owner’s own account, and is not offered to or used by anyone else. The sign-in token is stored only on the channel owner’s private computer. Data obtained from Google APIs is used solely for the purposes above; it is never sold, shared with third parties, used for advertising, or used to train AI models.

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service; see also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security settings at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent through the contact details on our YouTube channel’s About page.
