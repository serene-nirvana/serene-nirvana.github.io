Serene Nirvana Bot — API client overview

Private uploader for the YouTube channel @serene_nirvana.

What it is

A private desktop tool that runs only on the channel owner's own PC. It produces original relaxation videos (calm animated scenes with ambient soundscapes and music for sleep, study and focus) and publishes them to the owner's own channel. It has exactly one user, the channel owner, and is not offered to anyone else.

How it uses YouTube API Services

  • Upload & schedule: videos.insert (private with publishAt), thumbnails.set
  • Organise the channel: playlists.list, playlists.insert, playlistItems.insert
  • Avoid double-booking: channels.list (mine), playlistItems.list (own uploads), videos.list (status)
  • Learn what viewers like: YouTube Analytics reports.query on the owner's channel (views, minutes watched)
  • Scopes: youtube.upload, youtube, yt-analytics.readonly · Volume: about 3 videos + 3 Shorts per week

Data handling

The sign-in token is stored only on the owner's PC; the tool keeps only IDs of videos and playlists it created on the owner's channel; analytics are used at fetch time and raw analytics are not stored. No API data is sold, shared, used for advertising or used to train AI models. See the privacy policy and terms.

Content

Original illustrated scenes with music composed for the channel.
